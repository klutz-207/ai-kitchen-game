## 使用方式

### 如何使用开发阶段智能体

1. **产品设计智能体**
   - 把产品需求文档发给它
   - 让它完善细节、设计客人、写话术
   - 产出文档交给下一阶段

2. **前端开发智能体**
   - 把产品需求文档和交互流程发给它
   - 让它生成React代码
   - 产出前端代码

3. **后端开发智能体**
   - 把产品需求文档和智能体设计发给它
   - 让它生成Node.js代码
   - 产出后端代码

4. **测试集成智能体**
   - 把前后端代码发给它
   - 让它测试、集成、部署
   - 产出最终demo
