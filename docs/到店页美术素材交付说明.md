## 前端使用约束

1. 到店页背景使用 `arrival-standard.png` 或美术库副本，不要引用整张之外的错误重绘背景。
2. 客人全身图使用透明 PNG，前端统一控制显示高度和站位，不要为每个客人手动拉伸变形。
3. 头像使用 `avatars/` 下的头像图，不要在运行时从全身图硬裁。
4. `assets/art-library/sources/guests/*-chromakey.png` 是源稿留档，不接入运行时。
5. 锅仔素材只作为小角标、加载态或结算徽章使用，不遮挡主厨、客人、文字和按钮。
6. 不要把可变文案烘进新图片；客人名字、需求文案、按钮文字仍由前端渲染。

## 色彩与风格基准

- 主色：蜂蜜米色、焦糖棕、旧木色、砖红、暖橄榄、琥珀高光。
- 禁用：荧光绿、冷灰大面积铺色、高饱和橙、纯黑硬描边、明显像素风重绘。
- 角色质感：温暖手绘、柔和线条、细节充足，和到店参考图保持同一套温馨厨房气质。
