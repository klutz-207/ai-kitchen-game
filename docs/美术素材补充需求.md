# Demo美术素材补充需求

> 根据 2026-05-04 前端批注整理。现有人物素材不要修改，不重新裁切源文件；本需求只补充界面、场景、菜品、按钮与反馈页素材。

## 交付总要求

- 风格：保持当前温暖像素厨房风格，边缘清晰，适合网页内放大展示。
- 格式：优先 PNG，透明背景素材使用 alpha 通道。
- 倍率：建议按 2x 绘制，前端可缩放；关键 UI 边框需要避免模糊。
- 命名：使用英文小写短横线，放入 `assets/art-library/` 对应目录。
- 禁止：不要改动现有主厨与客人人物图，包括姿势、比例、表情、服装和透明边界。

- 对应批注：15、20、21、22

- 交付文件：
  - `backgrounds/dish-stage.png`
  - `backgrounds/fusion-ready-stage.png`
  - `backgrounds/feedback-stage.png`
- 建议尺寸：1920x1080。

  - `fusion-ready-stage`：两道菜准备融合的厨房台面，可有炉火、魔法光、搅拌器皿。
  - `feedback-stage`：客人试吃后的评价空间，左侧适合放客人，右侧适合放评价面板。
