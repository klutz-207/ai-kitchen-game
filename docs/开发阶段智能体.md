# 开发阶段智能体分工

## 概念区分

### 游戏内部智能体（运行时功能）
这是游戏本身的功能，由大模型驱动：
1. **图片生成智能体** - 生成像素风格图片
2. **客户反馈智能体** - 生成情感回复和数值评价
3. **引导智能体** - 引导用户创作

### 开发阶段智能体（开发分工）
这是开发流程的分工，由AI辅助开发：
1. **产品设计智能体** - 负责需求文档、交互设计
2. **前端开发智能体** - 负责React前端开发
3. **后端开发智能体** - 负责Node.js后端开发
4. **测试集成智能体** - 负责测试和部署

> 当前项目已进入 demo 收口阶段。以下分工继续有效，但产出目标从“从零生成代码”调整为“维护现有 React demo、Vercel API routes、mock fallback 和真实 AI pipeline”。

---

## 开发阶段智能体职责

### 1. 产品设计智能体
**职责**：
- 编写产品需求文档
- 设计交互流程
- 设计客人系统
- 设计引导话术
- 设计游戏内部智能体的提示词

**产出**：
- 产品需求文档
- 交互流程图
- 客人需求库
- 引导话术库
- 智能体提示词文档

---

### 2. 前端开发智能体
**职责**：
- React组件开发
- 页面布局实现
- 动画效果实现
- 对接后端API

**产出**：
- React组件代码
- 页面样式（Tailwind CSS）
- 动画效果（CSS/Canvas）

---

### 3. 后端开发智能体
**职责**：
- Node.js后端开发
- 智谱 GLM-4.7-flash 文本 API 集成
- 智谱 CogView-3-Flash 图像 API 集成，Stable Diffusion WebUI / PixelRTXL 作为可选本地模式
- Mock fallback 维护
- 游戏内部智能体逻辑实现
- 数据流处理

**产出**：
- Vercel Serverless API routes
- 智能体对话逻辑
- 图片生成逻辑
- 错误处理与 fallback 逻辑

---

### 4. 测试集成智能体
**职责**：
- 功能测试
- 前后端集成
- 部署上线
- 问题修复

**产出**：
- 测试报告
- 部署文档
- 最终demo
