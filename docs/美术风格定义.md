# 美术风格定义

## 风格总称

本项目当前形成的美术风格可以概括为：

```text
温暖手绘感像素童话厨房风
```

它不是硬核复古像素，也不是高精度二次元，而是介于：

```text
像素游戏素材
绘本简笔画
温暖厨房童话
Switch 独立游戏美术
```

之间的一种轻量、治愈、可直接用于游戏界面的风格。

## 视觉特征

### 1. 像素感：精致像素，不是硬核复古

本项目的像素风不是非常粗糙的 8-bit、FC、Game Boy 风格，而是更接近 Switch 独立游戏里的精致像素素材。

要求：

- 边缘有像素感。
- 造型保持柔软、圆润。
- 细节可以有，但不能复杂到影响小尺寸识别。
- 缩小到游戏界面尺寸后，主体仍然清楚。

避免：

```text
hard 8-bit
very low resolution
harsh pixel blocks
retro arcade only
```

### 2. 轮廓：圆润、亲切、容易识别

角色、菜品和道具都应有清晰剪影。

常见造型方向：

- 圆润厨师帽
- 柔软围裙
- 蝴蝶结
- 围巾
- 布料褶皱
- 小花点
- 缝线
- 蒸汽
- 星星特效

避免尖锐、冷硬、攻击性强的造型。

### 3. 配色：温暖厨房色系

推荐主色：

```text
奶油白
米色
焦糖棕
番茄红
鼠尾草绿
柔粉
暖黄
木色
浅橘
浅杏色
```

英文可写为：

```text
cream white
warm beige
caramel brown
tomato red
sage green
soft pink
warm yellow
wood brown
light peach
```

避免：

```text
neon colors
cyberpunk palette
cold blue-purple dominant palette
high contrast black and white
dark fantasy palette
```

### 4. 质感：手绘绘本感

素材可以有一点手绘的温度，不需要像机械像素图一样绝对规整。

可以出现：

- 轻微布料纹理
- 小花纹
- 缝线
- 柔和阴影
- 简单高光
- 手绘感边缘

但需要控制复杂度，不能变成厚涂插画或写实材质。

### 5. 背景：透明底游戏素材

本项目的角色、菜品、食材、特效，默认都应作为游戏资产生成。

要求：

```text
transparent background
no scene
no text
no logo
isolated object
clean edge
```

素材应能直接放入 React 前端页面，并可以被缩放、叠加、动画化。

## 厨师角色风格

厨师是玩家在游戏中的视觉代表，目前方向是：

```text
无脸背影角色
斜后方视角
身体朝右前方
像是在看右侧顾客
```

### 角色关键词

```text
faceless chef character
three-quarter back view
angled toward the right-front
looking at a customer offscreen to the right
no visible facial features
warm cozy kitchen outfit
apron bow
soft chef hat
rounded body shape
empty hands
transparent background
game sprite
```

### 姿态要求

厨师不应完全正面面对镜头，也不应完全背对镜头。推荐视角是：

```text
three-quarter back view
side-back view
angled to the right-front
```

也就是身体略微斜向右前方，像正在和右侧顾客互动。

### 手部动作

手上默认不要拿菜品或道具。

可用动作：

- 手自然垂在身体两侧。
- 一只手轻轻伸出，像在解释。
- 双手微微打开，像在回应顾客。
- 一只手靠近下巴、围巾或帽檐，表现思考。

避免：

```text
holding dish
holding plate
holding spoon
holding food
front-facing face
visible facial features
```
